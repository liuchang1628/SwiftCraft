# 项目复现指南

## 1. 环境准备

建议使用 Python 3.10+，核心依赖如下：

```bash
pip install pandas numpy duckdb scipy tqdm
```

看板为单文件 HTML，通过 CDN 引入 Tailwind CSS、ECharts 与 FontAwesome。双击 HTML 即可查看。

## 2. 数据生成

如需从原始 Instacart CSV 重新生成行为日志，运行：

```bash
python generate_quickmart_event_log.py
python generate_supporting_mocks.py
python generate_ab_test_results.py
```

生成的明细数据体量较大，不建议提交到 GitHub。

## 3. 数据集市计算

运行 DuckDB 聚合脚本：

```bash
python 05_duckdb_final_marts.py
```

核心输出为：

```text
mart_01_executive_summary.csv
mart_02_overall_funnel.csv
mart_03_funnel_channel.csv
mart_04_daily_city_oos.csv
mart_05_anomaly_trigger_diagnostic.csv
mart_06_retention_first_order_vs_non.csv
mart_07_feedback_oos_diagnostic.csv
mart_08_ab_test_summary.csv
```

## 4. 看板查看

打开以下任一页面即可通过左侧导航访问完整看板：

```text
dashboards/html/index.html
```

根目录也保留了一份工作副本：

```text
index.html
channel.html
funnel.html
supply.html
experiment_action.html
```

## 5. 导出截图和 PDF

本项目已导出：

```text
images/dashboard/*.png
exports/pdf/*.pdf
```

如果需要重新导出，可运行本项目提供的静态导出脚本：

```bash
python scripts/render_static_dashboard_exports.py
```

该脚本不依赖外部 CDN，会基于聚合 CSV 重新生成 GitHub 预览用 PNG 和 PDF。

如果希望导出交互式 HTML 的真实浏览器截图，也可以在网络可访问 CDN 的环境下使用浏览器“打印为 PDF”或开发者工具截图。

## 6. 项目交付校验

可运行 skill 内置检查脚本：

```bash
python skills/swiftcart-bi-project/scripts/check_project_package.py
```

它会检查核心 HTML 页面是否存在、导航数量是否一致、是否存在空链接，以及展示目录是否齐全。
