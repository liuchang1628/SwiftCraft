# 指标口径字典

## 时间窗口

| 口径 | 日期范围 |
| --- | --- |
| 分析周期 | 2026-04-01 至 2026-04-30 |
| 异常期 | 2026-04-21 至 2026-04-26 |
| 正常期 | 分析周期内除异常期外的日期 |

## 核心指标

| 指标 | 计算公式 | 业务含义 |
| --- | --- | --- |
| 新用户数 | `COUNT(DISTINCT user_id) WHERE action = '曝光'` | 当日进入首单漏斗的新用户规模 |
| 首单支付率 | `首单支付用户数 / 新用户数` | 新用户最终完成首单支付的比例 |
| D1 留存率 | `D+1 活跃用户数 / 当日新增用户数` | 新用户次日是否继续活跃 |
| 曝光 -> 点击率 | `点击 UV / 曝光 UV` | 前端兴趣转化 |
| 点击 -> 加购率 | `加购 UV / 点击 UV` | 商品兴趣到购物意图 |
| 加购 -> 结算率 | `结算 UV / 加购 UV` | 购物意图到交易发起 |
| 结算 -> 支付率 | `支付 UV / 结算 UV` | 交易后段完成能力 |
| Top20 缺货率 | `1 - Top20支付UV / Top20结算UV` | 爆款 SKU 在结算后被阻断的比例 |
| 缺货反馈率 | `缺货相关反馈数 / 总反馈数` | 客诉侧供给问题占比 |
| AB 首单绝对提升 | `Treatment转化率 - Control转化率` | 新策略相对原策略提升的百分点 |

## 关键分组维度

| 字段 | 说明 |
| --- | --- |
| `mock_date` | 模拟业务日期 |
| `period` | 正常期 / 异常期 |
| `channel` | 信息流渠道A、自然搜索、达人种草 |
| `city` | 北京、上海、广州、深圳、杭州、成都、武汉、南京 |
| `is_top20_product` | 是否为销量 Top20 爆款 SKU |
| `experiment_group` | Control / Treatment |

## 解释边界

- 可以表达为：当前证据支持“供给短缺是最完整候选解释”。
- 不建议表达为：库存是唯一根因。
- 可以表达为：AB 实验显示策略方向显著为正。
- 不建议表达为：策略可不经灰度直接全量上线。
